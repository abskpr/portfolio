# Abhishek Prakash - Personal Portfolio

A clean, minimalist, and highly performant personal portfolio website built to showcase my professional journey, skills, and certifications as a Senior Software Engineer specializing in Salesforce architecture.

*(You can add your GitHub Pages link here later, e.g., `https://[your-username].github.io/portfolio`)*

## ✨ Features
*   **Minimalist & Professional Design:** Focuses on typography and clean layout to enhance readability and user experience.
*   **Dark & Light Mode:** Built-in theme toggle with system preference detection and local storage persistence.
*   **High Performance:** Zero reliance on heavy third-party UI libraries or external icon servers. All company logos are either stored locally or rendered as crisp, inline SVGs.
*   **Responsive:** Fully responsive design that looks great on mobile devices, tablets, and large desktop screens.
*   **Smooth Scrolling:** Anchor links for seamless navigation across sections.

## 🛠️ Tech Stack
*   **HTML5:** Semantic and accessible structure.
*   **Tailwind CSS:** Utility-first CSS framework (loaded via CDN) for rapid and consistent styling.
*   **Vanilla JavaScript:** Lightweight DOM manipulation for the dark mode toggle and anti-flicker logic.

## 💻 Local Development
Since this project uses pure HTML, CSS, and JS with a Tailwind CDN, no build steps or package managers are required.

1.  Clone the repository:
    ```bash
    git clone https://github.com/your-username/your-repo-name.git
    ```
2.  Navigate to the project folder:
    ```bash
    cd your-repo-name
    ```
3.  Open `index.html` directly in your browser, or use a tool like VS Code's **Live Server** extension for hot-reloading as you make changes.

## 🚀 Deployment
This website is optimized for easy deployment via **GitHub Pages**.

1.  Push your code to a GitHub repository.
2.  Go to the repository **Settings**.
3.  Navigate to **Pages** on the left sidebar.
4.  Under "Build and deployment," set the Source to **Deploy from a branch**.
5.  Select your `main` or `master` branch and the `/ (root)` folder, then click **Save**.
6.  Your site will be live in a few minutes!
